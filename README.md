# Interstellar (2014) 🚀

## 🎬 About the Movie
**Interstellar** is a science fiction movie directed by *Christopher Nolan*. It follows the story of Cooper, a former pilot who travels through space to find a new home for humanity.

## ❤️ Why I Like This Movie
I like this movie because it combines science, adventure, and family emotions. It teaches us to never give up, even when facing difficult challenges.
